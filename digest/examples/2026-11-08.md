Two developer signals came in this week, one from GitHub and one from Slack, and both have been resolved. One flagged a possible error in the sample code in our API docs; the other asked how to get notified when a task's due date changes, rather than polling for it.

## Shipped and resolved

- **API docs: sample code reportedly contains an error** (docs gap, medium). A developer following the API docs hit an error in the sample code. [GitHub issue #1](https://github.com/MattBibi/asana-sandbox.github.io/issues/1)
- **Notifications: get alerted when a task's due date changes** (question, medium). A developer asked for a way to be notified of due-date changes instead of polling every minute. [Slack thread](https://bibis-workspace-group.slack.com/archives/C0CGSQFSW7J/p1794177894573309)
