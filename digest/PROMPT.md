Use the Asana MCP server to write this week's community update.

1. Find the Asana project named "Community Triage".
2. Read every task in it that was created or completed in the last 7 days. For each, note its name, section, its Source, Signal type and Priority fields, whether it is completed, and its description.
3. Only read from Asana. Do not create, edit, complete or comment on anything.

Then write the update in Markdown, for a developer community audience:

- A title with the date range, then two or three sentences on the week: how many signals came in, from where, and what stood out.
- **Shipped and resolved**: completed tasks, one line each, linking to the Source URL.
- **Open and being looked at**: open tasks grouped by Signal type, highest priority first, one line each.
- **Docs we're improving**: any docs gaps, as a short list.
- **Thank you**: anyone in the "Contributor to thank" section, by name.
- **Needs a decision**: tasks still in "Needs review", so the team can sort them.

Rules: use only what is in the tasks; don't invent numbers, names or dates. Write public-facing text, so leave out anything that reads as internal discussion. Skip a section that would be empty. Output only the Markdown, with no preamble.
